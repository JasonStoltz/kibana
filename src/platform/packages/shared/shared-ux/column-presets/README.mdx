## Description

Shared presets and cell renderers for `EuiBasicTable` and `EuiInMemoryTable`, used to keep
tabular data rendering consistent across Kibana.

## Column presets

Functions that return a partial column configuration. Spread the result into your column
definition.

| Export                | When to use                                                                                     |
| --------------------- | ----------------------------------------------------------------------------------------------- |
| `columnPresetActions` | Use this for Action columns in tables. It applies the standard fixed width and right alignment. |

```tsx
import { columnPresetActions } from '@kbn/shared-ux-column-presets';

const columns = [
  {
    ...columnPresetActions({}),
    name: 'Actions',
    actions: [
      /* ... */
    ],
  },
];
```

## Cell renderers

React components to return from a column's `render` function for consistent placeholder
content.

| Export            | When to use                                                                               |
| ----------------- | ----------------------------------------------------------------------------------------- |
| `EmptyCellValue`  | Use this for `null` or `undefined` values. Shows a `—` placeholder.                  |
| `EmptyCellString` | Use this for empty strings. Shows a localized `(Empty String)` placeholder. |

```tsx
import { EmptyCellValue, EmptyCellString } from '@kbn/shared-ux-column-presets';

const columns = [
  {
    field: 'description',
    name: 'Description',
    render: (value: string | null | undefined) => {
      if (value == null) return <EmptyCellValue />;
      if (value === '') return <EmptyCellString />;
      return value;
    },
  },
];
```
